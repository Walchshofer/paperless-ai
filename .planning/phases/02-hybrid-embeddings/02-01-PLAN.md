  <name>Task 3: Implement Reciprocal Rank Fusion (RRF)</name>
  <files>services/visual-rag/HybridSearchService.js</files>
  <action>
  Add RRF score fusion to HybridSearchService:

  RRF formula: score(d) = Σ 1 / (k + rank(d)) for each result list

  Implementation:
  ```javascript
  _fuseResults(visualResults, textResults, options = {}) {
    const k = options.k || 60; // RRF constant (standard is 60)
    const scoreMap = new Map(); // docId -> {score, visualRank, textRank, data}

    // Score visual results
    visualResults.forEach((result, index) => {
      const docId = result.docId;
      const score = 1 / (k + index + 1);
      scoreMap.set(docId, {
        score,
        visualRank: index + 1,
        textRank: null,
        data: result
      });
    });

    // Add text results
    textResults.forEach((result, index) => {
      const docId = result.doc_id || result.docId;
      const score = 1 / (k + index + 1);

      if (scoreMap.has(docId)) {
        const existing = scoreMap.get(docId);
        existing.score += score;
        existing.textRank = index + 1;
      } else {
        scoreMap.set(docId, {
          score,
          visualRank: null,
          textRank: index + 1,
          data: result
        });
      }
    });

    // Sort by fused score descending
    return Array.from(scoreMap.values())
      .sort((a, b) => b.score - a.score);
  }
  ```

  Also add weighted fusion option for alpha-based blending.
  Include source tracking (which list contributed to each result).
