# Bridge Configuration & Deployment Docs

This folder contains documentation for the CODEX↔Serena bridge (v4.x):

- `ENVIRONMENT_VARIABLES.md` — Bridge-specific environment variables and examples
- `CODEX_CONFIGURATION.md` — Example JSON configuration for starting the bridge from CODEX
- `DEPLOYMENT_CHECKLIST.md` — Step-by-step checklist for deploying the bridge (local, Docker, remote)
- `MIGRATION_V3_TO_V4.md` — Migration notes and rollback procedures
- `TROUBLESHOOTING.md` — Common error patterns and diagnostic steps
- `PERFORMANCE_TUNING.md` — Timeout and performance tuning recommendations

Follow these docs when installing or migrating to bridge v4.0.
