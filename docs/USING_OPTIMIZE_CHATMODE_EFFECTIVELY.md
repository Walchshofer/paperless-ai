# Using Optimize Chat Mode Effectively

This document defines when and how to use the @optimize chat mode in paperless-ai.

## What Optimize Is
The orchestration agent responsible for sequencing and enforcing guardrails.

## When to Use Optimize
- Prompt changes
- Pipeline changes
- Cross-cutting work

## When Not to Use Optimize
- Single-file trivial edits

## Recommended Default
Start with @optimize unless there is a strong reason not to.
