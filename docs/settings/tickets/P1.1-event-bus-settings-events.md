# Ticket P1.1 – Settings Event Bus Wiring

## Phase
Phase 1 – Infrastructure

## Objective
Register and validate all settings-related events in the global event bus.

## Scope
- Define schemas for:
  - settings:changed
  - settings:saved
  - settings:restart-required
  - preset:loaded
  - developer:toggled
- Register schemas in island runtime

## Constraints
- No UI changes
- No backend logic changes

## Acceptance Criteria
- Events dispatch and validate correctly
- No runtime errors
