## Objective
Allow users to export all current settings to a .env file for backup and deployment workflows.

## Scope
- Wire UI action to GET /settings/export
- Trigger file download:

  - Contents grouped by category with comments
- Ensure export includes all settings (~85+ entries)

## Constraints / Guardrails

- Do not change existing env variable semantics

## Acceptance Criteria
- Export produces valid .env file
- File downloads correctly across browsers
- Contents match current runtime configuration
