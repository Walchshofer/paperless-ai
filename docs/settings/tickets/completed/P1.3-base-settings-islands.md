# Ticket P1.3 – Base Settings Islands Scaffolding

## Phase
Phase 1 – Infrastructure

## Objective
Create non-functional scaffolding for core settings islands.

## Scope
- OverviewDashboardIsland
- SettingsSidebarIsland
- RestartBannerIsland
- Vite entry registration

## Constraints
- No business logic
- No styling finalization

## Acceptance Criteria
- Islands render placeholders
- Bundles produced successfully
- Playwright smoke test is present and verifies the islands mount (`test/e2e/settings_scaffolding.spec.ts`).

> Running locally: Playwright E2E may require services and auth. To run the new smoke test locally while skipping global service/auth/fixture setup, use (powershell):
>
> npx cross-env E2E_SKIP_SERVICE_CHECKS=1 E2E_SKIP_FIXTURE_SETUP=1 E2E_SKIP_AUTH_SETUP=1 npx playwright test test/e2e/settings_scaffolding.spec.ts --config=test/playwright.config.ts --reporter=html
