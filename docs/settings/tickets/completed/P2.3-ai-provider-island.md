# Ticket P2.3 – AIProviderIsland (Tabs + Save Semantics)

## Phase
Phase 2 – Core Settings Islands

## Objective
Implement the AI Provider island with internal tabs and the approved save/restart pattern.

## Scope
- Implement `AIProviderIsland` with internal tabs:
  - General, OpenAI, Ollama, Custom, Azure
- Implement provider selection in General tab with conditional tab content
- Implement save behavior:
  - Auto-save for non-critical fields (debounced per-island)
  - Critical changes saved immediately but restart deferred to banner (per PRD clarifications)
  - Flush debounced save on unmount/navigation
- Display restart-required indicators where relevant (badge/inline hint)

## Constraints / Guardrails
- No backend behavior changes; only wire to planned endpoints
- Must preserve exact runtime behavior for existing provider settings
- No renaming of env var keys or config paths

## Acceptance Criteria
- Tabs render and switch reliably
- Changing settings triggers the correct save pattern (auto-save + banner when restart needed)
- Rapid navigation does not lose pending changes (flush on unmount)
