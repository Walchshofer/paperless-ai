# Ticket P1.2 – Config Hot Reload Foundation

## Phase
Phase 1 – Infrastructure

## Objective
Introduce in-memory runtime overrides to support hot-reloadable settings.

## Scope
- Refactor config/config.js to getters
- Add runtimeOverrides map
- Add updateRuntime and clearRuntimeOverrides methods

## Constraints
- No behavior change at runtime
- Restart-required settings remain static

## Acceptance Criteria
- Application boots normally
- Overrides apply without restart for non-critical fields
