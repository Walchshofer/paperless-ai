Phase 4 – Presets & Polish

## Objective
Implement the Presets Manager island to allow users to load, review, and apply predefined configuration presets.

## Scope

## Acceptance Criteria

- Selecting a preset opens diff modal
- User can apply or cancel preset cleanly
