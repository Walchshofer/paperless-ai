# Ticket P4.3 – Settings Import (.env) + Diff

## Phase
Phase 4 – Presets & Polish

## Objective
Allow users to import settings from a .env file with validation and diff review before applying.

## Scope
- Implement import UI:
  - File picker for .env files
  - Upload to POST /settings/import
- Display diff modal (reuse preset diff UI)
- Apply imported settings only after confirmation

## Constraints / Guardrails
- Validation errors must be shown clearly
- All-or-nothing application only
- No silent partial imports

## Acceptance Criteria
- Invalid files are rejected with clear errors
- Valid imports show accurate diff
- Apply/cancel semantics work correctly
