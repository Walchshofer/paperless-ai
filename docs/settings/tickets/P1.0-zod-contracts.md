# Ticket P1.0 – Zod Contracts for Settings Domains

## Phase
Phase 1 – Infrastructure

## Objective
Define Zod schemas for all settings domains to ensure validated, typed boundaries between UI and backend.

## Scope
- Create Zod schemas for:
  - Connection
  - AI Provider
  - Expert Models
  - Advanced Settings
  - Developer Settings
- Store contracts under `src/ui/contracts/`

## Constraints
- No behavior changes
- Validation only
- Mirror existing config structure

## Acceptance Criteria
- All schemas compile
- Schemas align with existing config fields
