# Ticket P4.1 – Preset Diff Modal (Grouped Review)

## Phase
Phase 4 – Presets & Polish

## Objective
Provide a clear, grouped diff review UI for preset application.

## Scope
- Implement diff modal UI:
  - Group changes by category
  - Expand/collapse sections
  - Highlight changed values (before/after)
- Modal actions:
  - Apply Preset (all changes)
  - Cancel (no changes)

## Constraints / Guardrails
- No selective application
- No mutation until user confirms apply
- Visual-only diff (no inline editing)

## Acceptance Criteria
- Diff groups render correctly
- Apply/Cancel semantics are unambiguous
- Modal closes cleanly in all cases
