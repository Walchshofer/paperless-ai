# Ticket P0.0 – shadcn/ui Compatibility Validation

## Phase
Phase 0 – UI Library Validation

## Objective
Validate whether shadcn/ui (Radix UI primitives) is compatible with the existing Preact Islands architecture.

## Scope
- Install Tailwind as build dependency
- Install shadcn/ui + Radix dependencies
- Configure Vite with `preact/compat`
- Render Tabs, Dialog, Input, Switch in isolation

## Constraints
- No production usage
- No refactors
- Validation only

## Acceptance Criteria
- Automated tests (Vitest + testing library) that mount `Tabs`, `Dialog`, `Input`, and `Switch` pass with no runtime exceptions.
- Manual smoke test: an isolated island page (`/islands/shadcn-compat`) loads in dev server with no console errors and the components are interactive.
- Bundle impact: `npm run build` shows bundle size increase within acceptable bounds (see `docs/settings/TECH_PLAN.md`) or a documented mitigation plan is produced.
- Artifacts committed to a results doc with screenshots, test logs, and a clear Proceed / Pivot recommendation.

## Test Plan
1. Install dev dependencies (dev-only):
   - `npm install -D tailwindcss postcss autoprefixer vitest @testing-library/preact @vitejs/plugin-react-refresh`
   - `npm install class-variance-authority clsx tailwind-merge @radix-ui/react-tabs @radix-ui/react-label @radix-ui/react-switch @radix-ui/react-dialog`
2. Add minimal Tailwind config (`tailwind.config.cjs`) and `postcss.config.cjs` (see examples in `docs/settings/HANDOFF_IMPLEMENTATION.md`).
3. Update `vite.config.ts` to include `preact/compat` aliases (`'react': 'preact/compat', 'react-dom': 'preact/compat'`).
4. Create an isolated test island: `src/islands/shadcn-compat.tsx` that imports and renders `Tabs`, `Dialog`, `Input`, and `Switch` with minimal props.
5. Add automated test: `src/islands/__tests__/shadcn-compat.test.tsx` using Vitest and `@testing-library/preact` that mounts the island and asserts no thrown errors and basic interaction (open dialog, toggle switch).
6. Run `npm run test` and `npm run dev` for manual smoke checks at `http://localhost:3000/islands/shadcn-compat` (capture screenshots).
7. Build (`npm run build`) and measure `dist` size; include delta in results.
8. Produce `docs/settings/tickets/P0.0-shadcn-compatibility-results.md` summarizing steps, pass/fail, logs, screenshots, build sizes, and a Proceed/Pivot recommendation.

## Artifacts (expected)
- `src/islands/shadcn-compat.tsx`
- `src/islands/__tests__/shadcn-compat.test.tsx`
- `docs/settings/tickets/P0.0-shadcn-compatibility-results.md` (report with screenshots + sizes)

## Notes
- Do not merge changes to main or deployable branches until Phase 0 Decision Gate signals **Proceed**. Keep shadcn/ui code behind feature branch and flags.
