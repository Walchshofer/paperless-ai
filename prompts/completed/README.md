# prompts/

This directory contains working prompts, drafts, and research artifacts used during development and experimentation.

These files are intentionally ignored to avoid committing sensitive, draft, or noisy files to the repository and to keep the main repo history clean.

**Tracking rule:** The directory is ignored by default, but this `README.md` is tracked and documents the reason; if you want to keep any other specific file in source control, add an explicit exception to `.gitignore` (for example, `!/prompts/important-file.md`) and commit it intentionally.
